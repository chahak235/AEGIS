# Lesson 1: HTTP basics

- Client asks, server answers.
- 127.0.0.1 = this computer. 8000 = port (door number for a program).
- HTTP = shared rules for requests and responses.
- GET = read. POST = create. PATCH/PUT = update. DELETE = remove.
- 200 OK, 201 Created, 422 bad data, 401 not logged in, 403 not allowed, 404 not found, 500 server error.
- JSON = text format for structured data.
