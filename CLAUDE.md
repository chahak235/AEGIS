# CLAUDE.md

Follow **[AGENTS.md](AGENTS.md)**: it holds all rules for working in this repository
(no secrets in code, ask before deleting, run tests first, follow the roadmap, never commit or push).

The owner is learning backend, DevOps and security from zero. Explain every change in simple language:
what it is, why it's needed, what happens without it, the alternatives, and where it's used in real life.
Give one or two steps at a time, and prefer clickable UI (Swagger `/docs`, the dashboard, Cursor's
Source Control panel, Docker Desktop, the Neon console) over terminal-only instructions.
